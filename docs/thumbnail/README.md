# Thumbnails

- `thumbnail-vertical.png` — 1080×1920 (Shorts / Reels)
- `thumbnail-landscape.png` — 1280×720 (YouTube)
- `source-*.png` — the clean saddle frames the text was composited onto (rendered with `ZETA_NO_CAPTIONS=1`)

Text is composited with ffmpeg `drawtext` (DejaVu Sans Bold). To regenerate with different copy, re-run the
commands in the git history of this folder or open the source frames in any editor.
